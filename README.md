# IT Helpdesk Ticket Analytics & Automation Engine

An intelligent IT operations engine simulating batch processing, SLA tracking, and statistical anomaly detection for 50,000+ enterprise support tickets.

## Features
- **ETL & Data Warehouse:** Generates and processes 50,000+ support tickets with modular resolution metrics and SLA breach calculations.
- **Incident & Anomaly Detection:** Employs rolling mean and standard deviation (Z-score) thresholding to automatically flag hourly ticket volume spikes and system outages.
- **Interactive Analytics Dashboard:** Built using Streamlit and Plotly to monitor KPIs, SLA compliance rates, and simulate a ~15% resolution time reduction via Tier-1 support automation.

## Tech Stack
- **Languages & Frameworks:** Python, Streamlit, Plotly
- **Data Engineering:** Pandas, NumPy, SQLite
- **Concepts:** Time-series Anomaly Detection, SLA Tracking, What-If Scenario Modeling
